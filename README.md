# 🐧 Linux System Administration Lab

This repository documents my hands-on Linux learning and practical exercises as part of my AWS Cloud & DevOps training.

## 🎯 Goal

The goal is not only to memorize Linux commands, but to understand what each command or concept does, why it is used, how it works in practice, and how it connects to AWS and DevOps.

## 📚 Topics

1. Basic Linux Commands
2. Files & Directories
3. Users & Groups
4. File Permissions
5. Process Management
6. Package Management
7. Disk & Storage
8. Filesystems & Mounting
9. SSH
10. Linux Troubleshooting
11. Shell Scripting

## 🧪 How Each Topic Is Documented

Every topic contains:
- `README.md` — explanations, commands, examples and interview tips
- `practice.md` — hands-on exercises, actual outputs, screenshots, errors and solutions

I will update the practice files with my own results as I complete each lab.

> I will only claim commands, tools and exercises that I have actually learned or practiced.
